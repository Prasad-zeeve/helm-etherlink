# Etherlink Helm Chart

This Helm chart deploys Etherlink on a Kubernetes cluster.

## Prerequisites

- Kubernetes 1.19+
- Helm 3.0+

## Installation

To install the chart with the release name `my-etherlink`:

```bash
helm install my-etherlink ./charts/etherlink
```

## Uninstallation

To uninstall/delete the `my-etherlink` deployment:

```bash
helm uninstall my-etherlink
```
